# Retail Sales Case Study using Databricks SQL

## Project Overview

This project demonstrates how Databricks SQL can be used to analyse retail sales data and generate business insights. The analysis focuses on sales trends, pricing, profitability, promotional periods, and Price Elasticity of Demand (PED).

The project was completed as part of a practical data analytics case study using Databricks.

---

## Objectives

The objectives of this project were to:

- Analyse retail sales data using SQL.
- Calculate unit price and sales trends.
- Measure gross profit and gross profit percentage.
- Identify promotional periods.
- Calculate the Price Elasticity of Demand (PED).
- Generate business insights and recommendations.

---

## Dataset

The dataset contains retail sales transactions, including:

- Date
- Sales
- Cost
- Quantity Sold

These fields were used to perform SQL analysis and create business insights.

---

## Key Findings

- Sales changed over different periods.
- Lower prices generally resulted in higher quantities sold.
- Promotional periods increased customer demand.
- PED analysis showed that customer demand responds to price changes.
- Sales data can be used to improve pricing decisions.

---

## Business Recommendations

- Continue using promotional campaigns during slower sales periods.
- Monitor product pricing regularly.
- Use historical sales data to improve future planning.
- Focus on products with strong sales performance.
- Continue analysing customer purchasing behaviour.
